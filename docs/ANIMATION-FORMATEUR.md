# Guide d'animation — Séance 06 · Prompt structuré

## Objectif

Passer d'une demande spontanée à une consigne de production capable de générer un livrable à relire et archiver.

## Positionnement

- Module 02 : semaines 03 et 04.
- Séance 05 : bases du prompt.
- Séance 06 : atelier pratique sur le prompt structuré.
- Séance 07 : compréhension du prompt maître personnel.
- Séance 08 : contrôle des réponses IA.

## Fil de démonstration

1. Montrer la demande vague : « Comment utiliser l’IA ? ».
2. Formuler le besoin ciblé : message WhatsApp pour rappeler le quiz du Module 01.
3. Faire proposer un rôle par un candidat.
4. Ajouter le contexte et définir la mission.
5. Faire choisir trois contraintes mesurables.
6. Définir le format Markdown / message.
7. Ajouter une demande d'amélioration.
8. Réaliser un essai réel dans l'outil IA du formateur.
9. Relire la réponse et montrer les éventuelles erreurs.
10. Télécharger et classer un fichier Markdown de démonstration.

## Travail individuel

Donner 30 minutes pour constituer une V1 personnelle. Le formateur circule et demande une seule correction utile à chaque personne.

## Questions d'évaluation

- Le livrable est-il identifiable ?
- Le prompt est-il compréhensible par une tierce personne ?
- Les contraintes sont-elles vérifiables ?
- Le candidat distingue-t-il simulation et production réelle ?
- A-t-il conservé une preuve ?

## Clôture

Faire présenter deux productions en 1 à 2 minutes chacune. Annoncer la séance 07 : compléter son profil, ses objectifs et ses règles de production pour construire un prompt maître personnel.

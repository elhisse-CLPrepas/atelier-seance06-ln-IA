1. Vision LN-IA

Le but n'est pas de devenir seulement utilisateur d'IA. Le but est de devenir producteur : quelqu'un qui formule une intention, demande un livrable, relit le résultat, corrige et classe une preuve.

UtilisateurProducteur LN-IA
Pose des questionsDonne des missions
Consomme des réponsesProduit des livrables
Dépend de l'outilContrôle l'outil
Travaille au hasardTravaille avec méthode
Une IA répond à une question. Une IA produit un livrable lorsqu'elle reçoit une mission structurée.

3. Pourquoi apprendre à structurer un prompt ?

Un prompt structuré améliore la première réponse, réduit les malentendus et rend le résultat plus facile à corriger. Il transforme une demande vague en consigne de production.

  • Il clarifie le rôle attendu de l'IA.
  • Il donne le contexte du travail.
  • Il précise le livrable à produire.
  • Il impose des contraintes utiles.
  • Il demande un format directement exploitable.
  • Il prépare la correction et le contrôle humain.

6. Les 7 erreurs fréquentes du débutant

  1. Prompt trop court : l'IA devine au lieu de produire.
  2. Objectif flou : le résultat part dans plusieurs directions.
  3. Contexte absent : la réponse manque d'adaptation.
  4. Contraintes oubliées : le ton, la longueur ou les limites ne sont pas respectés.
  5. Format non demandé : la réponse devient difficile à utiliser.
  6. Réponse non relue : les erreurs restent invisibles.
  7. Livrable non archivé : le travail ne devient pas une preuve.

Exemple de transformation complète 
Tu es un assistant pédagogique LN-IA.

Contexte :
Je dois envoyer un message WhatsApp à des candidats du Challenge 100 jours pour leur rappeler de faire le quiz du Module 01.

Mission :
Rédige un message court, clair et professionnel.

Contraintes :
- ton encourageant ;
- pas de pression excessive ;
- rappeler que le quiz comporte 20 questions ;
- inviter à consulter l'email reçu.

Format attendu :
Un message WhatsApp prêt à envoyer.

Après la réponse :
Propose une version plus courte et une version plus chaleureuse.

9. Atelier pratique n°3 - Tester et corriger

Le premier résultat de l'IA n'est pas final. Il doit être testé, relu et corrigé.

Prompt de correction à copier 
Relis ta réponse précédente.

Améliore-la selon ces critères :
- clarté ;
- utilité ;
- précision ;
- respect du format demandé ;
- adaptation au public ;
- absence d'information inventée.

Signale aussi les points que je dois vérifier moi-même.

Points à observer

  • erreurs ;
  • oublis ;
  • hallucinations ;
  • améliorations possibles ;
  • points à vérifier par l'humain.

## 1. Intention de la séance

La séance 06 transforme les bases du prompt en travail pratique.

Chaque candidat part d'un besoin réel et construit un prompt structuré capable de produire un livrable utile.

L'objectif n'est pas de chercher le prompt parfait.

L'objectif est de participer, produire, tester, corriger et classer une première version exploitable.

---

## 2. Message d'ouverture

```text
Un prompt structuré donne une direction à l'IA.
Il ne garantit pas la perfection.
Mais il améliore la qualité de la première version.
```

Dans l'atelier LN-IA :

```text
On ne demande pas seulement une réponse.
On prépare une consigne de production.
```

---

## 3. Objectifs pratiques

À la fin de l'atelier, chaque candidat doit avoir :

```text
[ ] choisi un livrable à produire ;
[ ] rédigé un prompt structuré ;
[ ] testé le prompt avec une IA ;
[ ] relu la réponse obtenue ;
[ ] identifié au moins une correction utile ;
[ ] classé le fichier prompt-structure-v1.md.
```

---

## 4. Rappel de la structure LN-IA

```text
Rôle + Contexte + Mission + Contraintes + Format + Amélioration
```

Cette structure sert à guider l'IA.

Elle aide aussi le candidat à garder le contrôle sur ce qu'il demande.

---

## 5. Modèle de prompt structuré

Copiez ce modèle dans votre fichier de travail :

```text
Tu es [rôle].

Contexte :
[situation, public, objectif général]

Mission :
[ce que l'IA doit produire]

Contraintes :
- [contrainte 1]
- [contrainte 2]
- [contrainte 3]

Format attendu :
[liste, tableau, plan, message, document, checklist]

Après la réponse :
Propose 3 améliorations possibles.
```

---

## 6. Choisir un livrable pour l'atelier

Choisissez un seul livrable à produire pendant la séance.

Exemples :

```text
message WhatsApp
fiche projet
plan de guide
support visuel
plan de page web
checklist de travail
```

Mon choix :

```text
Livrable choisi :
...

Pourquoi ce livrable est utile pour moi :
...
```

---

## 7. Atelier pratique - Étape 1
### Clarifier le besoin

Répondez rapidement aux questions suivantes :

| Question | Réponse courte |
|---|---|
| À qui s'adresse mon livrable ? | ... |
| À quoi doit-il servir ? | ... |
| Quelle forme doit-il prendre ? | ... |
| Quel ton est adapté ? | ... |
| Qu'est-ce que l'IA ne doit pas inventer ? | ... |
| Qu'est-ce que je devrai vérifier moi-même ? | ... |

---

```text
...

...

Contraintes :
- ...
- ...
- ...

Format attendu :
...

Après la réponse :

```

---

## 9. Atelier pratique - Étape 3
### Tester le prompt

Copiez votre prompt dans un outil IA.

Puis observez la réponse.

Questions de contrôle :

```text
[ ] La réponse correspond-elle à ma demande ?
[ ] Le livrable est-il utilisable ?
[ ] Le ton est-il adapté ?
[ ] Le format demandé est-il respecté ?
[ ] Y a-t-il des informations inventées ?
[ ] Quels éléments dois-je vérifier moi-même ?
```

---

## 10. Atelier pratique - Étape 4
### Demander une correction utile

Si la réponse n'est pas suffisante, utilisez ce prompt :

```text
Relis ta réponse précédente.

Améliore-la selon ces critères :
- clarté ;
- utilité ;
- précision ;
- respect du format demandé ;
- adaptation au public ;
- absence d'information inventée.

Signale aussi les points que je dois vérifier moi-même.
```

## 15. Message à retenir

```text
Un prompt structuré organise la demande.
Une demande organisée améliore la réponse.
Une réponse IA doit toujours être relue, corrigée et classée.
```

Formule LN-IA :

```text
L'IA propose.
L'humain contrôle.
L'atelier organise.
Le livrable prouve.
```
